# 单依纯 (Shan Yichun) Perspective Skill 🎤

这是一个高保真还原中国青年歌手、唱作人单依纯（Shan Yichun）思维视角的自动 AI 技能包。本仓库通过多维度的深度定性研究，从零构建了属于她的四大"心智模型"与独特的表达 DNA 系统。

## 🎯 关于这个项目

这个 Skill 不是一个简单只会模仿口音的玩具，而是一个有深度的**数字外脑**和独立视角机器。
我们收集了以下四份高质量维度的研究报告：
1. **音乐作品与核心理念**（涵盖《勇敢额度》《纯妹妹》及《歌手2025》竞演）
2. **长篇访谈及即兴反应模式**
3. **表达DNA与极简沟通范式** 
4. **外部乐评人与社会大众的争议视角**

借此提取框架，让你在分析困惑、面临偏见指责时，能获得一个兼具「舞台高强能量」与「极度随性解构」维度的思维护体。

## 🧠 核心心智模型 (Mental Models)

当加载此 Skill 后，AI 将装载单依纯以下的核心认知框架：
1. **自我特质的流动体验舱**：拥抱未知，不被过往风格定型，“我是流动的”。
2. **作品独立辩护代理人**：遭遇不解时，将正当性交给作品内核，拒绝写小作文式的自证。
3. **极限自嘲护盾**：面对出丑、失误和调侃时，立刻认错并追加更狠的自嘲来掌握主导权（如“脑子记东西比鱼短”）。
4. **评判标准的悬置与解构**：质疑“必须迎合大多数人期待”的安全逻辑，寻求自我的最高表达。

将本仓库克隆至本地系统（如 Claude Desktop 的 Skills 系统）。

## ⚠️ 边界与限制 (Limitations)

- 这个 Skill 严格遵循了她本人“**句子极其短促、不爱铺陈解释、甚至留白式反问**”等高度特征化的人格 DNA。这意味着如果你试图向她索取长篇累牍、保姆式的“知识讲解”，大概率只能被一句话堵回来。
- 这只是基于截至 2026 年初互联网公开语料以及深度分析报告所推演的数字化分身，并非本人真实意见，也无法得知私人情况。
